# 首版交付验证记录

验证日期：2026-10-03。Node 25.4、Vite 7.3.6、MediaPipe tasks-vision 0.10.32、Python 3.14；本地 Mac 环境，未公开部署。

| 验证 | 结果 |
| --- | --- |
| `npm run build` | TypeScript + Vite 构建成功，静态产物在 `dist/` |
| `npm run test` | 58 / 58 通过 |
| Playwright 完整套件 | 45 / 45 通过，Chromium、桌面 WebKit、移动 Safari 模拟环境 |
| 触控命中范围调整后的工作流复验 | 21 / 21 通过；包括近点触控拖动、描线、侧脸锚点与完整 PNG |
| `backend/.venv/bin/python -m pytest backend/tests -q` | 40 / 40 通过，全部模拟上游，无付费 API 调用 |
| `dist/` 模型 / WASM 哈希 | 6 个资源全部符合 SHA256 锁 |
| 最终静态构建真实模型验证 | Chrome / WebKit 均产生四个面部锚点及候选轮廓，无页面错误 |
| 本地 HTTPS | 使用生成的 CA 验证证书与页面响应成功 |
| HTTP / HTTPS / preview 同源 AI 代理 | 后端健康接口响应 `ready:false`，无密钥模式正确保留本地功能 |
| 算法评估 | 16 个真实模型运行条件；样本与 JSON/CSV 保存在 `evaluation/` |

端到端覆盖照片导入、零差异与相似变换、不同尺寸及 EXIF 旋转/镜像、头发改变不影响面部配准、编辑/触控坐标、喜欢切换、删除遮挡锚点、保存及恢复、损坏文件拒绝、SVG 轮廓合成至 PNG、长标题与完整长备注、姿态不匹配时展示参考及停止量化、模型失败后重试、主动 AI 同意与失败回退。

桌面与移动截图见 [desktop.png](screenshots/desktop.png) / [mobile.png](screenshots/mobile.png)。截图使用绘制演示数据；自动算法验证使用单张公开领域人像及其明确标记的 Canvas 派生样本。

静态构建的本机首次照片分析观测约 1.4 秒，包含模型加载、导入和打开锚点编辑器；这不是跨设备性能保证。带网络响应录制的开发端测试会明显增加大型 WASM 传输耗时，不能用其耗时推断手机表现。

同发型派生图仍有候选误差：旋转/平移条件下外轮廓绝对偏移约 4.44–5.57%，较小占框缩放约 5.87–6.35%，轻度光照变化约 0.95–0.97%，单位为参考面部尺度。它们反映识别稳定性，不是实际头发变化。严重光线/占框条件停止量化，模拟 yaw=35° 的元数据条件触发重拍。详见 [评估方法及限制](../evaluation/README.md)。

尚未验证实体 iPhone 的相册/拍照、HEIC/HDR、原生触控捕获、内存压力及 Safari 后台恢复；未验证真实同人、同发型、多角度/距离/光照的物理拍摄队列，也未使用真实 OpenAI 账户。移动 WebKit 模拟、Canvas 派生照片和模拟 API 响应不能代替这些验证。
